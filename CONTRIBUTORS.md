# Contributors and Team Responsibilities

## About the Team

This repository is a collaborative Machine Learning project developed as part of the Python for Data & AI program at Uplift Code Camp.

Our team is working on three Machine Learning tasks: Classification, Regression, and Clustering. Each member has a primary area of responsibility and shared responsibilities in documentation, quality assurance, project review, and final presentation.

Our goal is to ensure that every contributor makes a meaningful technical and collaborative contribution to the project.

## Team Members and Responsibilities

### 1. Carlo Sismundo — Classification Lead

**Primary responsibility:** Hotel Booking Cancellation Prediction

Responsibilities:
- Lead the classification workflow, including data cleaning and preparation.
- Conduct exploratory data analysis and feature preparation.
- Develop and evaluate classification models.
- Compare model performance using appropriate classification metrics.
- Document the classification methodology, results, and limitations.
- Participate in peer reviews of the regression and clustering projects.
- Help ensure consistent code quality and documentation across the repository.

**Expected deliverables:**
- Classification Jupyter Notebook
- Cleaned and ML-ready dataset, where appropriate
- Model evaluation results and visualizations
- Classification project README

### 2. Erika — Time Scheduler and Project Coordinator

**Primary responsibility:** Project coordination, scheduling, and progress monitoring

Responsibilities:
- Create and maintain the project timeline and milestone schedule.
- Coordinate meetings, progress updates, and task assignments.
- Track task completion, dependencies, blockers, and upcoming deadlines.
- Ensure that each member has a balanced workload and meaningful technical responsibilities.
- Coordinate integration of the three Machine Learning projects.
- Review repository organization, README consistency, and completeness of deliverables.
- Contribute to technical reviews, testing, interpretation of results, and final presentation.
- Help resolve coordination issues and communicate changes to the team.

**Expected deliverables:**
- Project schedule and milestone tracker
- Task assignment and progress records
- Integration and completion checklist
- Repository-wide documentation review
- Contribution and final presentation coordination

**Important:** The coordinator role supports the technical work; it does not replace a member's responsibility to contribute to the Machine Learning project.

### 3. Kezelle — Regression Lead

**Primary responsibility:** Ames Housing Price Prediction

Responsibilities:
- Contribute to housing dataset inspection, cleaning, and validation.
- Conduct exploratory data analysis to understand housing prices and relevant features.
- Help develop preprocessing pipelines for numerical and categorical variables.
- Develop, tune, or evaluate regression models.
- Analyze regression metrics such as MAE, RMSE, and R².
- Review residuals, feature importance, and potential model limitations.
- Document technical decisions and results in the regression project README.
- Participate in peer reviews of the classification and clustering projects.

**Expected deliverables:**
- Regression notebook contributions
- Data analysis and preprocessing documentation
- Model evaluation and interpretation
- Regression project README updates

### 4. Allen — Clustering Lead

**Primary responsibility:** Unsupervised Machine Learning and Clustering

Responsibilities:
- Inspect and prepare the selected clustering dataset.
- Conduct exploratory data analysis and identify relevant features.
- Apply appropriate preprocessing and scaling when required.
- Develop and compare suitable clustering approaches.
- Evaluate cluster quality using appropriate methods, such as silhouette score when applicable.
- Visualize and interpret discovered groups or patterns.
- Document the clustering methodology, findings, and limitations.
- Participate in peer reviews of the classification and regression projects.

**Expected deliverables:**
- Clustering Jupyter Notebook
- Data preparation and exploratory analysis
- Cluster visualizations and evaluation
- Clustering project README

## Shared Responsibilities

All team members are expected to contribute to the overall quality of the repository, regardless of their primary assignment.
