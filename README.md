# Machine Learning Projects Portfolio

A collaborative Machine Learning portfolio developed as part of our **Python for Data & AI training at Uplift Code Camp**. This group project demonstrates our practical application of data preparation, exploratory data analysis, preprocessing, model development, and evaluation using Python.

Our repository is organized into three independent Machine Learning projects: Classification, Regression, and Clustering. Each project has an assigned team member responsible for its development.

## Projects

### 1. Classification — Hotel Booking Cancellation Prediction

**Assigned to:** Carlo Sismundo

**Objective:** Predict whether a hotel booking will be canceled based on booking information.

This project applies classification algorithms to a hotel booking dataset. It covers data cleaning, exploratory data analysis, feature preparation, model training, and evaluation.

**Key activities:**
- Data cleaning and preparation
- Exploratory Data Analysis (EDA)
- Feature selection and preprocessing
- Classification model training and comparison
- Evaluation using accuracy, precision, recall, F1-score, and a confusion matrix

**Main tools:** Python, Pandas, NumPy, Matplotlib, Seaborn, and Scikit-learn

[View the Classification Project](Classification)

### 2. Regression — Ames Housing Price Prediction

**Assigned to:** Erica and Kizzele

**Objective:** Predict residential property sale prices using housing characteristics.

This project uses regression techniques to estimate house prices. It includes data preparation, exploratory analysis, preprocessing pipelines, cross-validation, model comparison, and evaluation on a held-out test set.

**Key activities:**
- Data cleaning and validation
- Exploratory Data Analysis (EDA)
- Numerical and categorical feature preprocessing
- Baseline model development
- Ridge Regression and Random Forest Regression
- Hyperparameter tuning and cross-validation
- Evaluation using MAE, RMSE, and R²
- Residual analysis and feature importance

**Main tools:** Python, Pandas, NumPy, Matplotlib, and Scikit-learn

[View the Regression Project](Regression)

### 3. Clustering — Unsupervised Learning

**Assigned to:** Allen

**Objective:** Explore patterns and potential groups within data using unsupervised Machine Learning.

This project focuses on discovering groups or structures in a dataset without relying on a predefined target variable.

The project documentation and notebook cover the dataset, preprocessing steps, clustering methods, visualizations, and evaluation approach.

**Main tools:** Python, Pandas, NumPy, Matplotlib, and Scikit-learn

## Machine Learning Workflow

Each project follows a workflow appropriate to its Machine Learning task:

1. **Data Understanding** — Examine the dataset, columns, data types, and relevant variables.
2. **Data Cleaning** — Check missing values, duplicates, inconsistent values, and data quality issues.
3. **Exploratory Data Analysis** — Use summary statistics and visualizations to identify patterns and relationships.
4. **Feature Preparation** — Select relevant features and prepare numerical and categorical variables where applicable.
5. **Model Development** — Establish baseline performance and train suitable Machine Learning models.
6. **Model Evaluation** — Apply metrics appropriate to classification, regression, or clustering.
7. **Interpretation** — Analyze findings, model performance, limitations, and possible improvements.

## How to Explore the Projects

1. Open the project folder you want to explore.
2. Read its `README.md` for the project objective, dataset, methodology, and findings.
3. Open the Jupyter Notebook in the `notebooks/` folder.
4. Review the code, visualizations, preprocessing steps, and model evaluation.

To run a notebook locally, install the required Python libraries, update any dataset paths as needed, and execute the cells in order.
